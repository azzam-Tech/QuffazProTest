# موقع قفّاز · Quffaz

موقع تعريفي سينمائي من صفحتين (عربي RTL) لشركة إنتاج إعلامي سعودية.

## الملفات
- `index.html` — الصفحة الرئيسية (هيرو فيديو، قصّتنا، خدماتنا مرئي/صوتي، 16 مقطع مرئي، معرض صور، مشاريع خاصة، شركاء، تواصل).
- `portfolio.html` — معرض الأعمال (هيرو إحصائيات + شبكة أعمال بفلاتر ملوّنة).
- `styles.css` — كل التنسيقات والثيم والتجاوب.
- `script.js` — توليد الوسائط من Drive، الفلاتر، النافذة المنبثقة، التفاعلات.

## النشر على GitHub Pages
1. ارفع الملفات الأربعة + `hero.mp4` في **نفس المجلد** (جذر المستودع).
2. فعّل GitHub Pages من إعدادات المستودع (الفرع `main` / المجلد `root`).
3. كل المسارات نسبية، فالموقع يعمل مباشرةً دون تعديل.

## نقاط تحتاج انتباهك
- **فيديو الهيرو:** سمِّ ملفك `hero.mp4` بالضبط وضعه بجانب `index.html`. تظهر صورة بديلة إن لم يُحمّل.
- **وسائط Google Drive:** المعرّفات في أعلى `script.js` (`IMG_IDS` و`VIDEO_IDS`). الموقع يجرّب صيغتي رابط لكل صورة (`drive.google.com/thumbnail` ثم `lh3.googleusercontent.com/d/`)، وإن فشلتا يضع خلفية متدرّجة بديلة آمنة.
- **شرط ظهور الصور (مهم):** يجب أن يكون كل ملف على Drive مُشاركاً للعموم. الأسرع: افتح المجلد في Drive ← حدّد كل الملفات ← «مشاركة» ← غيّر الوصول العام إلى **«أي شخص لديه الرابط» بصلاحية «مُشاهد»**. للتأكد، افتح `https://drive.google.com/thumbnail?id=المعرّف&sz=w1600` في المتصفح؛ إن ظهرت الصورة فالربط سليم.
- **واتساب:** الرقم في `index.html` تجريبي `wa.me/966500000000` — بدّله برقمك.
- **نموذج التواصل:** شكلي للعرض فقط (يُظهر رسالة شكر بدون إرسال فعلي). لربطه لاحقاً استخدم خدمة مثل Formspree أو بريد back-end.
- **العناوين والشعارات:** عناوين الأعمال وأسماء الشركاء افتراضية للتجربة — عدّلها في `script.js` (مصفوفتا `REEL` و`PORTFOLIO`) وفي قسم الشركاء داخل `index.html`.
